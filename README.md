# YouTube Danmaku Comments

YouTubeの動画コメントを、ニコニコ動画風にプレイヤー上へ流すユーザースクリプトです。現在のバージョンは **1.0.0** です。

## インストール

1. ブラウザーに [Tampermonkey](https://www.tampermonkey.net/) をインストールします。
2. Tampermonkeyのダッシュボードで新規スクリプトを作成します。
3. [YouTubeDanmakuComments.js](YouTubeDanmakuComments.js) を開き、先頭のメタデータを含む全文でエディターの内容を置き換えて保存します。
4. YouTubeの動画ページを開きます。すでに開いている場合は再読み込みしてください。

Greasy Forkでの配布は公開予定です。

## 使い方

プレイヤー右下の **弾** ボタンをクリックすると、弾幕の表示を切り替えられます。右クリックで設定を開きます。

- `0:30 ここすき` のようなコメントは、動画の0分30秒に「ここすき」と表示されます。返信はタイムスタンプの直後から0.5秒間隔で流れます。
- タイムスタンプのないコメントは、動画の再生時間全体に分散して表示されます。
- 設定では、文字サイズ・色・縁取り・透明度・表示範囲・流れる速さなどを変更できます。コメント取得件数と返信取得の設定は、次の動画を開いたときに反映されます。

## 動作範囲

- YouTubeの通常の動画ページ（`/watch`）が対象です。Shortsと配信中のライブは対象外です。
- コメント取得にはYouTubeの内部APIを使います。コメント欄が無効な動画では表示できず、YouTube側の仕様変更によって動かなくなる場合があります。
- 1.0.0ではページ単位でコメントを取得するため、最後に受け取ったページの分だけ設定件数を超える場合があります。
- コメント取得時のリクエストにCookieは送信しません。表示設定はブラウザーのローカルストレージに保存します。
